# hangman_gleam

![hangman_gleam Logo](/docs/logo.svg)

hangman_gleam — a classic Hangman game for the terminal, written in [Gleam](https://gleam.run/)

Features:

🎮 Minimalist terminal interface

🔀 Random word selection

🦀 Implemented in Gleam without loops

🔎 No if/else statements

🚫 No exceptions


## Development

```sh
gleam run   # Run the project
gleam test  # Run the tests
```
